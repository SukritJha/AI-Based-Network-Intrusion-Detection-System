# AI-Based Network Intrusion Detection System

An AI-powered Network Intrusion Detection System (NIDS) using
Random Forest and the CIC-IDS-2017 dataset.

## Features
- Machine Learning–based intrusion detection
- Random Forest classifier
- Confusion matrix, ROC & PR curves
- Live traffic simulation (dataset-based)
- Streamlit dashboard

## Tech Stack
- Python
- Scikit-learn
- Streamlit
- Matplotlib & Seaborn

## Dataset
CIC-IDS-2017 (Friday Afternoon DDoS)
Dataset not included due to size.

## How to Run
```bash
pip install -r requirements.txt
streamlit run nids_main.py
